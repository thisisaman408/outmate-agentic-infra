# Outmate AI Agents - API Testing Guide

This guide provides the exact steps to test your AI Agent backend using Postman.

**Base URL:** `http://localhost:5000`

---

## 1. Agentic Search (Gemini)
**Goal:** Search for companies using natural language.

1.  **Method:** `POST`
2.  **URL:** `http://localhost:5000/api/agents/search`
3.  **Headers:**
    *   `Content-Type`: `application/json`
4.  **Body (JSON):**
    ```json
    {
      "query": "Find B2B SaaS companies in New York focusing on marketing automation"
    }
    ```
5.  **Expected Output:**
    *   A list of company objects generated by Gemini that match criteria.
    *   Status: `200 OK`

---

## 2. Research Agent (Gemini)
**Goal:** Get a full research report on a specific company.

1.  **Method:** `POST`
2.  **URL:** `http://localhost:5000/api/agents/research`
3.  **Headers:**
    *   `Content-Type`: `application/json`
4.  **Body (JSON):**
    ```json
    {
      "companyName": "Tesla"
    }
    ```
5.  **Expected Output:**
    *   A JSON object with `summary`, `marketPosition`, `opportunities`, `risks`, etc.
    *   Status: `200 OK`

---

## 3. Predictive Agent (Gemini)
**Goal:** Score a list of leads based on likelihood to convert.

1.  **Method:** `POST`
2.  **URL:** `http://localhost:5000/api/agents/score-leads`
3.  **Headers:**
    *   `Content-Type`: `application/json`
4.  **Body (JSON):**
    ```json
    {
      "leadIds": ["1", "2", "3"]
    }
    ```
5.  **Expected Output:**
    *   A JSON array where each item has a `conversionLikelihood` score (0-100) and a `recommendation`.
    *   Status: `200 OK`

---

## Troubleshooting

- **Error: "Search query is required"**
    - Check if your Body is set to `raw` -> `JSON` in Postman.
- **Error: 500 Internal Server Error**
    - Check your terminal where `npm run dev` is running.
    - If it says `GoogleGenerativeAI Error`, check your `.env` file and ensure `GEMINI_API_KEY` is correct.
