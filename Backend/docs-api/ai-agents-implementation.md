# AI Agents Logic & Real AI Integration

This document explains the logic behind the "Real AI" integration for Outmate and how to set it up.

## 1. Setup

### Dependencies
The following packages have been added to `package.json`:
- `@google/generative-ai`: Client for the Gemini API.
- `axios`: Client for making HTTP requests (kept for future use).

**Action Required:**
Running `npm install` may have failed due to permissions. **Please run the following command manually in your terminal:**
```bash
npm install @google/generative-ai axios
```

### Environment Variables
Updated `.env` (or create one based on `.env.example`) to include:
```env
GEMINI_API_KEY=your_key_here
```
- **Gemini Key**: Get it from [Google AI Studio](https://aistudio.google.com/).

---

## 2. Feature Implementation Logic

### A. Agentic Search (Gemini Powered)
**Logic:**
1.  **Input:** User query (e.g., "SaaS companies in Austin").
2.  **Process:** The backend sends a prompt to **Gemini Pro** asking it to act as a "Sales Prospector".
3.  **Output:** Gemini generates a JSON list of companies that match the description.

### B. Research Agent (Gemini Powered)
**Logic:**
1.  **Input:** Company Name.
2.  **Process:** The backend sends a prompt to **Gemini Pro** asking it to act as a "Corporate Researcher".
    - Unlike Perplexity, this relies on Gemini's *internal training data*. It will be accurate for well-known companies up to its knowledge cutoff. For unknown or fictional companies, it will generate plausible profiles for testing purposes.
3.  **Output:** Comprehensive report (Summary, Market Position, Risks, etc.) generated by the LLM.

### C. Predictive Agent (Gemini Powered)
**Logic:**
1.  **Input:** List of Lead IDs.
2.  **Process:** The backend packages lead data into a text prompt for **Gemini**.
3.  **Output:** Gemini returns a reasoned score and recommendation.

### D. Lookalike Agent (Vector Search Strategy)
**Current Status:** Simplistic Mock.
**Recommended Implementation:**
1.  **Database**: Store company descriptions in PostgreSQL with `pgvector` extension.
2.  **Embedding**: When a seed company is selected, generate an embedding vector of its description using `geminiModel.embedContent()`.
3.  **Search**: Query the database for the nearest neighbor vectors (Cosine Similarity).
    ```sql
    SELECT * FROM companies ORDER BY embedding <-> '[0.1, 0.2, ...]' LIMIT 5;
    ```
