1. **Statistics** → gauge market size

5. **Events/Webhooks** → monitor real-time changes

## Complete Build Plan: Intents & Signals Feature

### Phase 1: Foundation — Match & Identify

**Goal:** Resolve your target accounts/prospects to Explorium IDs.

| Step | API Endpoint | Purpose |
|---|---|---|
| 1a | `POST /v1/businesses/match` | Match company name/domain → get `business_id` |
| 1b | `POST /v1/prospects/match` | Match person name/company → get `prospect_id` |

```bash
# Match a business
curl -X POST https://api.explorium.ai/v1/businesses/match \
  -H "api_key: YOUR_KEY" \
  -d '{"businesses_to_match": [{"name": "Apple", "domain": "apple.com"}]}'
```

---

### Phase 2: Intent Signals (Bombora)

**Goal:** Detect what topics companies are actively researching.

**Endpoint:** `POST /v1/businesses/bombora_intent/bulk_enrich`

**Key parameters:**
- `business_ids` — up to 50 per request
- `topics` — semicolon-separated "category: topic" list (use **at least 12 topics** for meaningful results)
- `min_score` — integer > 60 (default: 60)

**Use Autocomplete first** to get valid topic values:
`GET /v1/businesses/autocomplete?field=business_intent_topics&semantic_search=true`

**Output signals:**

| Signal | Description |
|---|---|
| `level_of_intent` | In-Depth Research (>25%), Active Research (5–25%), Early Research (<5%) |
| `topic_count` | e.g., "4/12" — topics with score above threshold |
| `intent_topics` | Array of topic name, category, composite_score, date |
| `date_stamp` | Weekly refresh date (YYYYMMDD) |

```bash
curl -X POST https://api.explorium.ai/v1/businesses/bombora_intent/bulk_enrich \
  -H "api_key: YOUR_KEY" \
  -d '{
    "business_ids": ["8adce3ca1cef0c986b22310e369a0793"],
    "parameters": {
      "topics": ["training & development: corporate universities;training & development: career management;...12+ topics"],
      "min_score": 76
    }
  }'
```

---

### Phase 3: Enrichment Signals (Layer on Context)

Combine intent data with these enrichments for a full picture:

| Signal Type | Endpoint | Key Data |
|---|---|---|
| **Firmographics** | `POST /v1/businesses/firmographics/bulk_enrich` | Name, revenue, employees, industry, NAICS/SIC, locations |
| **Website Traffic** | `POST /v1/businesses/website_traffic/bulk_enrich` | Visits, bounce rate, traffic sources, device breakdown |
| **Business Challenges** | `POST /v1/businesses/pc_business_challenges_10k/bulk_enrich` | Competition, security breaches, market saturation (public companies) |
| **Financial Indicators** | `POST /v1/businesses/financial_indicators/bulk_enrich` | EBITDA, revenue, ROA, P/E ratio |
| **Contact Details** | `POST /v1/prospects/contacts_information/enrich` | Emails, phone numbers, mobile |
| **Professional Profile** | `POST /v1/prospects/profiles/enrich` | Job title, skills, education, work history |

---

### Phase 4: Real-Time Event Monitoring

**Goal:** Get notified when key changes happen.

| Endpoint | Purpose |
|---|---|
| `POST /v1/businesses/events/enrollments` | Enroll businesses for events (funding, IPO, M&A, workforce changes) |
| `POST /v1/prospects/events/enrollments` | Enroll prospects for events (role change, company change, job anniversary) |
| `POST /v1/webhooks` | Receive real-time event notifications |

### Best Practices from the Docs:
- **Always provide 12+ intent topics** for meaningful Bombora results
- **Use Autocomplete with `semantic_search=true`** to build accurate topic lists
- **Batch up to 50 IDs** per bulk enrichment request
- **Combine intent + firmographic + event data** for full go-to-market insights
- **Weekly refresh cadence** for Bombora intent data
- **Store API keys securely** — never hardcode them
