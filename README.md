# Outmate

The GTM Engine for your agents. Outmate is a low-code agent infrastructure layer that allows you to build, orchestrate, and deploy powerful AI agents for Go-To-Market products.

## Getting Started

### Prerequisites
* Python (uv recommended)
* Node.js (v22+)

### Fast Start
```bash
make run_cli
```

### Development Mode
1. **Initialize:** `make init`
2. **Backend:** `LFX_DEV=1 make backend`
3. **Frontend:** `make frontend`

Built on top of a modular graph execution engine.
